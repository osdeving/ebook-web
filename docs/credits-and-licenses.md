# Créditos, fontes e licenças

Todo recurso externo precisa registrar: autor, título/descrição, página de
origem, licença com link direto, alterações feitas e data de acesso. Não use
uma imagem encontrada na busca sem chegar à página original e confirmar a
licença.

O framework é MIT. Conteúdo de capítulo não herda essa licença; consulte
`CONTENT_LICENSE.md`. Dependências e seus avisos estão resumidos em
`THIRD_PARTY_NOTICES.md`; o lockfile registra as versões efetivamente usadas.
