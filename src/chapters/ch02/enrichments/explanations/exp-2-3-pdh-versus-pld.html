O PLD pede a causa escondida — o expoente. O PDH pede apenas um efeito específico produzido por duas causas escondidas — a potência \(g^{ab}\). Recuperar uma causa fornece informação suficiente para calcular o efeito, mas calcular esse efeito particular pode não revelar a causa.

Definição

PLD: de \(g\) e \(A=g^a\), recuperar \(a\). PDH: de \(A=g^a\) e \(B=g^b\), calcular \(g^{ab}\).

Manipulação

Suponha disponível um algoritmo para o PLD. Aplicamo-lo a \(A\) e obtemos \(a\); depois calculamos \(B^a=(g^b)^a=g^{ab}\). Assim, um resolvedor do PLD pode ser usado como sub-rotina para resolver o PDH.

Teorema

Essa redução prova apenas a desigualdade de dificuldade na direção indicada: o PDH não é mais difícil que o PLD. Ela não prova que ambos tenham a mesma dificuldade.

Observe que nem sequer precisamos recuperar os dois expoentes. Conhecer \(a\) basta para elevar o valor público \(B\) a \(a\); conhecer \(b\) também bastaria para elevar \(A\) a \(b\).

Inverter a seta exigiria mostrar como transformar qualquer algoritmo eficiente para o PDH em um algoritmo eficiente para o PLD. O texto afirma corretamente que essa recíproca não é conhecida; não se deve substituir essa lacuna por uma suposta equivalência.
