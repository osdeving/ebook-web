Depois de uma volta completa no relógio das potências, chegamos novamente ao mesmo ponto. Por isso, o expoente não é um endereço absoluto: ele é uma posição cíclica, determinada apenas a menos de voltas completas.

Teorema

O pequeno teorema de Fermat fornece \(g^{p-1}\equiv1\pmod p\) para \(g\ne0\).

Manipulação

Se \(g^x\equiv h\), adicionar uma volta completa ao expoente não muda a potência:

\[g^{x+(p-1)}=g^xg^{p-1}\equiv h\cdot1\equiv h\pmod p.\]

Repetindo o argumento, todo \(x+k(p-1)\) descreve a mesma potência.

Definição

Assim, \(\log_g(h)\) é uma classe em \(\mathbb Z/(p-1)\mathbb Z\). Escolher um representante entre \(0\) e \(p-2\) é apenas uma convenção para escrever essa classe com um único inteiro.

No exemplo \(p=7\), \(g=3\), temos \(3^2\equiv2\pmod7\). Também \(3^8=3^{2+6}\equiv2\) e \(3^{14}=3^{2+2\cdot6}\equiv2\). Portanto, todos os expoentes \(\ldots,-4,2,8,14,\ldots\) representam o mesmo logaritmo, isto é, \(2\bmod6\).

O módulo mudou: os valores da potência são reduzidos módulo \(p\), mas os expoentes são identificados módulo \(p-1\). Misturar esses dois módulos é uma fonte frequente de erros.
