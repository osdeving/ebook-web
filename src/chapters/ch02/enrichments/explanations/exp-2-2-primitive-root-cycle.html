Pense nas potências de \(g\) como passos em um relógio multiplicativo. A cada passo, multiplicamos pelo mesmo \(g\) e reduzimos módulo \(p\). Uma raiz primitiva dá uma volta completa: visita cada posição não nula exatamente uma vez antes de retornar a \(1\).

Teorema

Quando \(p\) é primo, existe pelo menos um elemento primitivo em \(\mathbb F_p^*\). Como esse conjunto tem \(p-1\) elementos, uma raiz primitiva tem ordem \(p-1\).

Definição

Dizer que \(g\) é uma raiz primitiva significa que as potências \(g^0,g^1,\ldots,g^{p-2}\) produzem todos os elementos de \(\mathbb F_p^*\), sem repetição nessa faixa.

Manipulação

Com \(p=7\) e \(g=3\), reduzimos a cada multiplicação:

\[3^0\equiv1,\quad3^1\equiv3,\quad3^2\equiv2,\quad3^3\equiv6,\quad3^4\equiv4,\quad3^5\equiv5\pmod7.\]

O passo seguinte retorna ao início: \(3^6\equiv1\pmod7\). A lista \(1,3,2,6,4,5\) contém exatamente os seis resíduos não nulos.

Se escolhêssemos \(g=2\) no mesmo módulo, obteríamos \(2,4,1,2,\ldots\): o ciclo tem apenas três posições. Logo, \(2\) não é raiz primitiva módulo \(7\), embora seja um elemento perfeitamente válido de \(\mathbb F_7^*\).

Em \(\mathbb F_p\), escrever \(3^4=4\) é uma igualdade entre classes de resíduos. Ao trabalhar com inteiros, a mesma ideia aparece como a congruência \(3^4\equiv4\pmod7\). Não se está afirmando que \(81=4\) nos inteiros.
