1. Como \(F\) é finito, dois elementos da sequência \(1,2\cdot1,3\cdot1,\ldots\) coincidem: \(r\cdot1=s\cdot1\) para algum \(r>s\). Subtraindo, \((r-s)\cdot1=0\). Assim existe um inteiro positivo com a propriedade pedida.
  2. Se o menor \(m\) fosse composto, \(m=uv\) com \(1<u,v<m\). Pela minimalidade, \(u\cdot1\ne0\) e \(v\cdot1\ne0\), mas \[ (u\cdot1)(v\cdot1)=(uv)\cdot1=m\cdot1=0, \] criando divisores de zero em um corpo. Contradição; logo \(m=p\) é primo.
  3. A aplicação \(\mathbb Z\to F\), \(n\mapsto n\cdot1\), tem núcleo \(p\mathbb Z\) e identifica \(\mathbb F_p\) com o subcorpo primo de \(F\). A adição de \(F\) e a multiplicação por elementos desse subcorpo satisfazem os axiomas de espaço vetorial. Como \(F\) é finito, uma base não pode ter infinitos vetores; sua dimensão \(d\) é finita. Além disso, \(d\ge1\), pois \(1\ne0\) e, portanto, \(F\) não é o espaço vetorial nulo.
  4. Cada vetor de uma base com \(d\) elementos possui exatamente \(p\) escolhas para cada coordenada. Portanto \[ |F|=p^d. \]
