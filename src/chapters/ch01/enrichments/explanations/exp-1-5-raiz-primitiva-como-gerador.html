Uma raiz primitiva é um elemento cujo ciclo é tão longo quanto possível. Suas potências servem como um sistema de coordenadas para todos os elementos não nulos do corpo.

Gerador

Se \(\operatorname{ord}(g)=p-1\), então \(1,g,g^2,\ldots,g^{p-2}\) são \(p-1\) elementos distintos de \(\mathbb F_p^*\). Como o grupo tem exatamente esse tamanho, a lista contém todos.

Expoentes como endereços

Para cada \(h\in\mathbb F_p^*\), existe \(x\) módulo \(p-1\) com \(g^x=h\). Encontrar \(h\) a partir de \(x\) é exponenciação; recuperar \(x\) a partir de \(h\) é o problema do logaritmo discreto.

Teste com fatores

Para \(g\in\mathbb F_p^*\), se conhecemos a fatoração de \(p-1\), basta verificar que

\[g^{(p-1)/q}\not\equiv1\pmod p\]

para cada primo \(q\mid p-1\). Isso impede que a ordem seja um divisor próprio de \(p-1\).

Para \(p=11\), os primos que dividem \(10\) são \(2\) e \(5\). Como \(2^5\equiv10\ne1\) e \(2^2\equiv4\ne1\), a ordem de \(2\) é \(10\); logo \(2\) é raiz primitiva.

O teorema garante raízes primitivas em \(\mathbb F_p^*\). Nem todo grupo de unidades \((\mathbb Z/m\mathbb Z)^*\) para módulo composto é cíclico.
