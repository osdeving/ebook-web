1. Além de serem restos consecutivos do algoritmo de Euclides, os valores mantêm os invariantes

    \[g\equiv au\pmod b,\qquad y\equiv ax\pmod b.\]

    Eles valem na inicialização: \(g=a\), \(u=1\), \(y=b\) e \(x=0\). Se \(g=qy+t\) e \(s=u-qx\), então

    \[t=g-qy\equiv a(u-qx)=as\pmod b.\]

    Depois das atribuições, os dois invariantes voltam a valer para os novos pares \((g,u)=(y,x)\) e \((y,x)=(t,s)\). Os restos diminuem estritamente, por isso o processo termina com \(y=0\). Nesse instante, o algoritmo de Euclides garante \(g=\gcd(a,b)\), e \(g\equiv au\pmod b\) mostra que

    \[v=\frac{g-au}{b}\in\mathbb Z,\qquad au+bv=g.\]

  2. Uma implementação com inteiros arbitrariamente grandes em JavaScript é:

    function mdcEstendido(a, b) {
  if (a <= 0n || b < 0n) {
    throw new RangeError("use a > 0 e b ≥ 0");
  }
  if (b === 0n) return { g: a, u: 1n, v: 0n };

  let u = 1n, g = a, x = 0n, y = b;
  while (y !== 0n) {
    const q = g / y;
    const t = g - q * y;
    const s = u - q * x;
    [u, g, x, y] = [x, y, s, t];
  }
  return { g, u, v: (g - a * u) / b };
}

  3. Executando o algoritmo, obtemos:

    1. \(\gcd(527,1258)=17\), com \((u,v)=(-31,13)\), pois \(527(-31)+1258(13)=17\).
    2. \(\gcd(228,1056)=12\), com \((u,v)=(-37,8)\), pois \(228(-37)+1056(8)=12\).
    3. \(\gcd(163961,167181)=7\), com \((u,v)=(4517,-4430)\), pois \(163961(4517)+167181(-4430)=7\).
    4. \(\gcd(3892394,239847)=1\), com \((u,v)=(59789,-970295)\), pois \(3892394(59789)+239847(-970295)=1\).

  4. Sem o teste especial, o algoritmo chega imediatamente a \(y=0\) e tenta calcular \((a-a)/0\), uma divisão indefinida. A saída antecipada mostrada no código corrige o caso: \(\gcd(a,0)=a\) e \(a\cdot1+0\cdot0=a\).

  5. Se \(g=\gcd(a,b)\), todas as soluções têm \(u=u_0+k(b/g)\). Portanto reduzimos \(u_0\) módulo \(b/g\) ao menor representante estritamente positivo e ajustamos \(v\) pelo mesmo \(k\):

    function menorUPositivo(a, b, { g, u, v }) {
  if (b === 0n) return { g, u: 1n, v: 0n };
  const passoU = b / g;
  let uMin = ((u % passoU) + passoU) % passoU;
  if (uMin === 0n) uMin = passoU;
  const k = (uMin - u) / passoU;
  return { g, u: uMin, v: v - k * (a / g) };
}

    Refazendo o item (c), os pares com \(u\) mínimo positivo são, na mesma ordem:

    1. \((u,v)=(43,-18)\);
    2. \((u,v)=(51,-11)\);
    3. \((u,v)=(4517,-4430)\);
    4. \((u,v)=(59789,-970295)\).
