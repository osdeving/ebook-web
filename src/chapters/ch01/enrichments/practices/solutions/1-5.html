Uma cifra de substituição simples é uma permutação das \(26\) letras.

  1. Há

    \[26!=403\,291\,461\,126\,605\,635\,584\,000\,000\]

    permutações possíveis.

  2. Denote por \(D_n\) o número de desarranjos de \(n\) objetos, isto é, permutações sem pontos fixos. Pela inclusão-exclusão,

    \[D_n=n!\sum_{j=0}^{n}\frac{(-1)^j}{j!}.\]

    1. Nenhuma letra fixa:

      \[D_{26}=148\,362\,637\,348\,470\,135\,821\,287\,825.\]

    2. Pelo menos uma letra fixa é o complemento do caso anterior:

      \[26!-D_{26}=254\,928\,823\,778\,135\,499\,762\,712\,175.\]

    3. Para haver exatamente uma letra fixa, escolhemos essa letra de \(26\) maneiras e desarranjamos as outras \(25\):

      \[26D_{25}=148\,362\,637\,348\,470\,135\,821\,287\,824.\]

    4. Os casos “nenhuma”, “exatamente uma” e “pelo menos duas” formam uma partição. Logo o último número é

      \[26!-D_{26}-26D_{25}=106\,566\,186\,429\,665\,363\,941\,424\,351.\]
