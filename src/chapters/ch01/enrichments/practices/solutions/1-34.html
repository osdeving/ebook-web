Dica 1 — Teste apenas os fatores primos da ordem

Para verificar se \(g\) tem ordem \(p-1\), fatore \(p-1\) e teste se \(g^{(p-1)/q}\not\equiv1\pmod p\) para cada primo \(q\mid p-1\).

Dica 2 — Reaproveite quadraturas

Calcule \(g,g^2,g^4,\ldots\) uma vez por módulo. Combine essas potências para todos os expoentes do teste e para cada candidato.

Dica 3 — Gere todas as raízes a partir de uma

Se \(g\) é primitiva, as demais raízes primitivas são \(g^k\) com \(\gcd(k,p-1)=1\). Isso também explica a contagem por \(\phi(p-1)\).

Ver solução completa

Usaremos o seguinte teste. Se \(p\) é primo, então \(g\) é uma raiz primitiva módulo \(p\) se, e somente se,

\[ g^{(p-1)/q}\not\equiv1\pmod p \qquad\text{para todo primo }q\mid p-1. \]

De fato, essas verificações excluem todos os possíveis divisores próprios da ordem \(p-1\).

    • \(p=7\): \(2^3\equiv1\pmod7\), portanto \(2\) não é primitiva.
    • \(p=13\): \(2^6\equiv12\) e \(2^4\equiv3\pmod{13}\); como \(12=2^2\cdot3\), \(2\) é primitiva.
    • \(p=19\): \(2^9\equiv18\) e \(2^6\equiv7\pmod{19}\); como \(18=2\cdot3^2\), \(2\) é primitiva.
    • \(p=23\): \(2^{11}\equiv1\pmod{23}\), portanto \(2\) não é primitiva.

    Logo \(2\) é raiz primitiva exatamente para \(p=13\) e \(p=19\).

    • \(p=5\): \(3^2\equiv4\not\equiv1\pmod5\), portanto \(3\) é primitiva.
    • \(p=7\): \(3^3\equiv6\) e \(3^2\equiv2\pmod7\), portanto \(3\) é primitiva.
    • \(p=11\): \(3^5\equiv1\pmod{11}\), portanto \(3\) não é primitiva.
    • \(p=17\): \(3^8\equiv16\not\equiv1\pmod{17}\), portanto \(3\) é primitiva.

    Logo os primos pedidos são \(5,7,17\).

  3. Uma escolha para cada primo, acompanhada das verificações exigidas pelo teste, é

    \[ \begin{array}{c|c|l} p&g&\text{potências de teste}\\ \hline 23&5&5^{11}\equiv22,\quad5^2\equiv2\\ 29&2&2^{14}\equiv28,\quad2^4\equiv16\\ 41&6&6^{20}\equiv40,\quad6^8\equiv10\\ 43&3&3^{21}\equiv42,\quad3^{14}\equiv36,\quad3^6\equiv41 \end{array} \]

    Todos os resíduos da última coluna são diferentes de \(1\) no módulo correspondente; assim, podemos tomar \(5,2,6,3\), respectivamente.

  4. O número \(2\) é uma raiz primitiva módulo \(11\). Todo elemento não nulo é \(2^k\), e \(2^k\) é primitivo se, e somente se, \(\gcd(k,10)=1\). Os expoentes são \(k=1,3,7,9\), o que dá

    \[ 2^1\equiv2,\quad 2^3\equiv8,\quad 2^7\equiv7,\quad 2^9\equiv6\pmod{11}. \]

    Portanto todas as raízes primitivas módulo \(11\) são \(\{2,6,7,8\}\). Há \(4=\phi(10)\) delas.

  5. Um programa direto que implementa o teste acima é:

    def prime_divisors(n):
    factors = []
    d = 2
    while d * d <= n:
        if n % d == 0:
            factors.append(d)
            while n % d == 0:
                n //= d
        d += 1
    if n > 1:
        factors.append(n)
    return factors

def primitive_roots(p):
    qs = prime_divisors(p - 1)
    return [
        g for g in range(1, p)
        if all(pow(g, (p - 1) // q, p) != 1 for q in qs)
    ]

    A contagem confere, pois \(228=2^2\cdot3\cdot19\) e

    \[ \phi(228) =228\left(1-\frac12\right)\left(1-\frac13\right)\left(1-\frac1{19}\right) =72. \]

  6. Os primos menores que \(100\) para os quais \(2\) é raiz primitiva são

    \[ \{3,5,11,13,19,29,37,53,59,61,67,83\}. \]

  7. Para a base \(3\), obtemos

    \[ \{2,5,7,17,19,29,31,43,53,79,89\}. \]

    A inclusão de \(p=2\) usa a convenção usual de que \(1\) gera o grupo trivial \(\mathbb F_2^*=\{1\}\); se forem considerados apenas primos ímpares, basta omitir \(2\).

    Para a base \(4\), não há nenhum primo menor que \(100\). Para todo primo ímpar \(p\),

    \[ 4^{(p-1)/2}=2^{p-1}\equiv1\pmod p, \]

    logo a ordem de \(4\) é menor que \(p-1\); para \(p=2\), \(4\equiv0\) nem sequer pertence a \(\mathbb F_2^*\).
