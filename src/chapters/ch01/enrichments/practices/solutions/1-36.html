Dica 1 — Fatore a diferença de dois quadrados

Se \(x^2\equiv y^2\pmod p\), então \((x-y)(x+y)\equiv0\pmod p\). Em um corpo, isso restringe qualquer raiz a duas classes candidatas.

Dica 2 — Conte raízes locais sistematicamente

Para os exemplos pequenos, calcule \(0^2,1^2,\ldots,((p-1)/2)^2\pmod p\). A metade restante apenas repete as raízes com sinal oposto.

Dica 3 — Para módulo composto, combine escolhas

Fatore o módulo em fatores coprimos, encontre as raízes em cada fator e combine independentemente os sinais pelo teorema chinês dos restos.

Ver solução completa

  1. Suponha que exista uma raiz \(x\), isto é, \(x^2\equiv b\pmod p\). Como \(p\nmid b\), temos \(x\not\equiv0\pmod p\). O número \(-x\) também é raiz.

    Se \(y\) é qualquer outra raiz, então

    \[ 0\equiv y^2-x^2=(y-x)(y+x)\pmod p. \]

    Como \(p\) é primo, \(y\equiv x\) ou \(y\equiv-x\pmod p\). Além disso, essas duas soluções são distintas: se \(x\equiv-x\), então \(2x\equiv0\), o que, para \(p\) ímpar, implicaria \(x\equiv0\), uma contradição. Portanto, se há uma raiz, há exatamente duas; caso contrário, não há nenhuma.

    Para \(p=2\) e \(2\nmid b\), existe uma única solução, \(X\equiv1\pmod2\), pois \(1=-1\) em \(\mathbb F_2\). Se \(p\mid b\), a congruência é \(X^2\equiv0\pmod p\), que possui a única solução \(X\equiv0\pmod p\).

    1. \(3^2\equiv4^2\equiv2\pmod7\), logo as raízes são \(3\) e \(4\).
    2. \(4^2\equiv7^2\equiv5\pmod{11}\), logo as raízes são \(4\) e \(7\).
    3. Os quadrados módulo \(11\) são \(0,1,3,4,5,9\). Como \(7\) não aparece, não há raiz.
    4. \(15^2=225\equiv3\pmod{37}\); a outra raiz é \(-15\equiv22\pmod{37}\). Logo as raízes são \(15\) e \(22\).

  3. Reduzindo primeiro módulo \(5\) e módulo \(7\),

    \[ 29\equiv4\pmod5,\qquad29\equiv1\pmod7. \]

    Assim, uma raiz deve satisfazer \(X\equiv2\) ou \(3\pmod5\), e \(X\equiv1\) ou \(6\pmod7\). As quatro combinações, resolvidas pelo teorema chinês dos restos, são

    \[ \begin{array}{c|c|c} X\bmod5&X\bmod7&X\bmod35\\ \hline 2&1&22\\ 2&6&27\\ 3&1&8\\ 3&6&13 \end{array} \]

    Portanto \(29\) possui quatro raízes quadradas módulo \(35\):

    \[ X\equiv8,13,22,27\pmod{35}. \]

    Não há contradição com o item (a), porque \(35\) não é primo.

  4. A afirmação é para \(a\in\mathbb F_p^*\), pois \(0\) não é potência de uma raiz primitiva. Se \(k\) é par, escreva \(k=2j\). Então

    \[ a\equiv g^k=g^{2j}=(g^j)^2\pmod p, \]

    logo \(a\) possui a raiz quadrada \(g^j\).

    Reciprocamente, se \(x^2\equiv a\pmod p\), então \(x\ne0\) e, como \(g\) é primitiva, \(x\equiv g^j\) para algum \(j\). Portanto

    \[ g^{2j}\equiv x^2\equiv a\equiv g^k\pmod p. \]

    A ordem de \(g\) é \(p-1\), logo \(2j\equiv k\pmod{p-1}\). Como \(p-1\) é par, essa congruência força \(k\) a ser par. Assim, \(a\) possui raiz quadrada se, e somente se, \(k\) é par.
