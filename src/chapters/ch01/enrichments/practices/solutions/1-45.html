Dica 1 — Teste se cada regra é uma bijeção

Uma função define cifra somente quando, para cada chave admitida, mensagens distintas produzem textos cifrados distintos e existe uma inversa sobre todo o espaço.

Dica 2 — Procure ou construa a inversa

Para \(k-m\), aplique a regra duas vezes. Para \(km\), pergunte exatamente quando \(k^{-1}\pmod N\) existe.

Dica 3 — Busque colisões na regra quadrática

Compare mensagens simétricas em torno de \(-k\). Se duas delas sempre têm a mesma imagem, restringir apenas o conjunto de chaves não corrige a falta de injetividade.

Ver solução completa
  1. Sim. Para todo \(k\), a aplicação \(m\mapsto k-m\) é bijetiva e é sua própria inversa: \[ d_k(c)\equiv k-c\pmod N. \]
  2. Não para todo \(k\in\mathbb Z/N\mathbb Z\): multiplicar por um não invertível não é uma permutação. Restrinja as chaves a \[ \mathcal K=(\mathbb Z/N\mathbb Z)^*. \] Para essas chaves, \[ d_k(c)\equiv k^{-1}c\pmod N. \]
  3. Não. Para \(N>2\), os valores \(m\equiv-k+x\) e \(m'\equiv-k-x\) têm a mesma imagem \(x^2\), embora em geral sejam distintos. O problema ocorre para cada chave, portanto diminuir apenas o conjunto de chaves não torna a função uma cifra sobre o mesmo espaço de mensagens.
