Esta é uma tarefa de implementação e corpus: a solução fornece o programa completo; os números finais dependem dos arquivos escolhidos.

Dica 1 — Normalize antes de contar
Converta diacríticos, caixa e sequências não alfabéticas de forma explícita e reproduzível.
Dica 2 — Entropia de n-gramas
Calcule \(-\sum_gp_g\log_2p_g\) e compare \(H(L^n)/n\).
Dica 3 — Não cruze palavras sem querer
Para o modo pedido, gere n-gramas separadamente dentro de cada palavra.

O programa abaixo resolve as etapas [1]–[4] em JavaScript moderno. Execute com node entropia.mjs arquivo.txt.

Corpora sugeridos pelo enunciado: Alice's Adventures in Wonderland, Relativity: The Special and General Theory, The King James Version of the Bible e Twenty Thousand Leagues under the Sea. Registre a edição e o hash do arquivo baixado.

import { readFile } from "node:fs/promises";

const raw = await readFile(process.argv[2], "utf8");
const text = raw.normalize("NFD").replace(/\p{M}/gu, "")
  .toLowerCase().replace(/[^a-z]+/g, " ").trim();
const words = text.split(" ").filter(Boolean);

function counts(n) {
  const map = new Map();
  for (const word of words) {
    for (let i = 0; i + n <= word.length; i++) {
      const g = word.slice(i, i + n);
      map.set(g, (map.get(g) ?? 0) + 1);
    }
  }
  return map;
}

function report(n) {
  const map = counts(n);
  const total = [...map.values()].reduce((a, b) => a + b, 0);
  const grams = n === 1 ? [..."abcdefghijklmnopqrstuvwxyz"] : [...map.keys()];
  const rows = grams.map((g) => ({
    g, count: map.get(g) ?? 0, p: total === 0 ? 0 : (map.get(g) ?? 0) / total,
  })).sort((a, b) => b.count - a.count);
  const H = -rows.reduce((sum, row) =>
    row.p === 0 ? sum : sum + row.p * Math.log2(row.p), 0);
  console.log("n=" + n + "; amostras=" + total + "; H=" + H + "; H/n=" + (H / n));
  console.table(rows.slice(0, n === 1 ? 26 : 25));
}

report(1); report(2); report(3);

Os valores de \(H(L)\), \(H(L^2)/2\) e \(H(L^3)/3\) devem ser recalculados para cada obra. Comparar Carroll, Einstein, a Bíblia e Verne é a parte genuinamente experimental: tamanho, idioma, tradução, cabeçalhos do arquivo e política de acentos afetam o resultado. Por isso não há um único trio numérico correto sem fixar as edições e registrar seus hashes.

Errata de remissão no texto-base. A etapa [3] manda comparar com \(H(L)\) da etapa [1], mas a entropia de letras é calculada na etapa [2].
