Uma permutação usa todos os objetos exatamente uma vez; objetos repetidos exigem dividir pelas trocas invisíveis.

Dica 1 — Liste sistematicamente
Fixe o primeiro símbolo e permute os restantes.
Dica 2 — Use fatoriais
Para \(n\) objetos distintos há \(n!\) ordens.
Dica 3 — Conte a simetria invisível
Quando há símbolos repetidos, pergunte quantas permutações rotuladas produzem a mesma palavra depois de apagar os índices.
Ver solução completa

(a) ABC, ACB, BAC, BCA, CAB, CBA.

(b) 1234, 1243, 1324, 1342, 1423, 1432; 2134, 2143, 2314, 2341, 2413, 2431; 3124, 3142, 3214, 3241, 3412, 3421; 4123, 4132, 4213, 4231, 4312, 4321.

(c) \(\boxed{20!=2\,432\,902\,008\,176\,640\,000}\).

(d) \(\boxed{7!=5040}\).

(e) Das \(4!\) ordens rotuladas, trocar os dois A não cria palavra nova: \(\boxed{4!/2!=12}\).
