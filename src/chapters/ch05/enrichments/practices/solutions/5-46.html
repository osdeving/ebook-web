Para qualquer mensagem e qualquer texto cifrado existe exatamente um deslocamento que liga os dois.

Dica 1 — Permutação das mensagens
Quando \(k\) percorre 0–25, \(d_k(c)\) percorre cada letra clara uma vez.
Dica 2 — Uma chave favorável
Para \(m,c\) fixos, a única chave é \(k=c-m\pmod{26}\).
Dica 3 — Não suponha fonte uniforme
Deixe \(f_M\) simbólica; a bijeção das chaves deve fazer a soma valer \(1\) para qualquer distribuição de mensagens.
Ver solução completa

(a) Como \(k\mapsto d_k(c)\) é uma bijeção de \(\mathcal K\) em \(\mathcal M\),

\[\sum_{k\in\mathcal K}f_M(d_k(c))=\sum_{m\in\mathcal M}f_M(m)=1.\]

(b) Cada chave tem massa \(1/26\), então \(f_C(c)=\sum_k(1/26)f_M(d_k(c))=1/26\).

(c) Para \(m,c\) fixos, exatamente uma das 26 chaves produz \(c\), logo \(f(c\mid m)=1/26=f(c)\). Portanto o sistema tem sigilo perfeito, independentemente da distribuição das letras claras.
