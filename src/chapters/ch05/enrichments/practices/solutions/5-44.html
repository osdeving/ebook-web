A colisão precisa ocorrer módulo um fator antes de ocorrer módulo \(N\); então o mdc revela esse fator.

Dica 1 — Parte (a)
Uma função que mistura bem colide módulo \(p\) após \(O(\sqrt p)\) passos pelo paradoxo do aniversário.
Dica 2 — Registre falhas também
Se \(\gcd(|x-y|,N)=N\), os dois módulos colidiram juntos e aquela execução não fatorou.
Dica 3 — Observe \(x^2-2\)
Com início zero, a órbita entra rapidamente no ponto fixo 2.
Ver solução completa

(a) Projetada em \(\mathbb Z/p\mathbb Z\), a órbita se comporta como amostras de um conjunto de tamanho \(p\); uma colisão surge em \(O(\sqrt p)\). Antes da colisão módulo os demais fatores, \(p\mid x_k-y_k\) mas \(N\nmid x_k-y_k\), de modo que o mdc revela \(p\).

Errata provável na Proposição 5.44. Os valores \(z_1,\ldots,z_n\) devem ser escolhidos entre 1 e \(N\), em simetria com os \(y_i\); a letra \(k\) impressa nesse ponto não havia sido definida.

(b) Este programa completo usa Floyd e pode ser executado com node rho-fator.mjs:

function gcd(a, b) {
  while (b !== 0n) [a, b] = [b, a % b];
  return a < 0n ? -a : a;
}

function rhoFactor(N, c = 1n, x0 = 0n) {
  const f = (x) => (x * x + c) % N;
  let slow = x0, fast = x0, divisor = 1n, iteration = 0;
  while (divisor === 1n) {
    slow = f(slow);
    fast = f(f(fast));
    iteration++;
    divisor = gcd(slow - fast, N);
  }
  return { factor: divisor, iteration, failed: divisor === N };
}

const inputs = [2201n, 9409613n, 1782886219n];
for (const c of [1n, 2n]) {
  for (const N of inputs) console.log({ N, c, ...rhoFactor(N, c) });
}

(c) Com \(x^2+2\), os casos dão respectivamente \(k=6\) com mdc \(N\) (falha), \(k=6\) com fator 541 e \(k=68\) com fator 7933: o tempo muda e uma semente/função pode precisar ser trocada.

(d) Se \(N\) é primo, todo mdc é 1 ou \(N\); não existe fator não trivial.

(e) Para qualquer semente, a função \(f(x)=x^2\) produz

\[x_i=x_0^{2^i},\qquad y_i=x_0^{2^{2i}},\qquad g_i=\gcd\!\left(x_0^{2^i}-x_0^{2^{2i}},N\right).\]

A órbita é uma duplicação determinística de expoentes, não uma função misturadora; portanto a heurística de \(O(\sqrt p)\) não se aplica. Isso não significa falha para toda semente: o resultado depende das ordens de \(x_0\) módulo cada fator de \(N\). Por exemplo, com \(N=15\), \(x_0=1\) dá \(x_1=y_1=1\) e \(g_1=15\), uma falha trivial; já \(x_0=2\) dá \(x_1=4\), \(y_1=1\) e \(g_1=\gcd(3,15)=3\), uma fatoração imediata. Sementes divisíveis por um fator de \(N\), ou sementes que entram simultaneamente em ciclos módulo todos os fatores, também podem produzir fatores ou a falha \(g_i=N\). Assim, para “quaisquer” \(x_0\), deve-se analisar a órbita; não há um desfecho universal.

(f) Para \(x^2-2\) e \(x_0=0\), \(0\mapsto-2\mapsto2\mapsto2\), então tartaruga e lebre coincidem módulo todos os fatores e o mdc vira \(N\). A identidade sugerida explica a estrutura algébrica que impede a mistura.
