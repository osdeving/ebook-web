Uma contagem complicada costuma ser uma soma de perguntas sim/não. Indicadores transformam essa observação em álgebra.

Indicador

Defina \(I_j=1\) quando o evento j ocorre e \(I_j=0\) caso contrário. Então \(E(I_j)=\Pr(I_j=1)\).

Some antes de calcular

Se X conta quantos eventos ocorreram, \(X=\sum_jI_j\). Pela linearidade, \(E(X)=\sum_j\Pr(I_j=1)\).

Sem independência

A igualdade das esperanças não exige que os eventos sejam independentes. Independência seria necessária para certas variâncias ou probabilidades conjuntas, não para esta soma.

Em uma permutação uniforme de n objetos, cada posição é fixa com chance \(1/n\); logo o número esperado de pontos fixos é 1.
