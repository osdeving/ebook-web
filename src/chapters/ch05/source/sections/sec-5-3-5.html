5.3.5

Valor esperado

O valor esperado de uma variável aleatória \(X\) é a média de seus valores, ponderada pela probabilidade de ocorrência de cada um. Portanto, o valor esperado fornece uma primeira indicação aproximada do comportamento de \(X\).

Definição

Seja \(X\) uma variável aleatória que assume os valores \(x_1,\ldots,x_n\). O valor esperado, ou média, de \(X\) é a quantidade

(5.27)\[ E(X)=\sum_{i=1}^{n}x_i f_X(x_i) =\sum_{i=1}^{n}x_i\Pr(X=x_i). \]
Exemplo5.35

Seja \(X\) a variável aleatória cujo valor é a soma dos números obtidos no lançamento de dois dados. Os valores possíveis de \(X\) são os inteiros entre \(2\) e \(12\), portanto

\[E(X)=\sum_{i=2}^{12}i\Pr(X=i).\]

Há \(36\) resultados possíveis para os dois dados, como indica a Tabela 5.8(a). Nessa tabela, contamos de quantas maneiras a soma pode ser \(i\), para cada \(i\) entre \(2\) e \(12\), e reunimos os resultados na Tabela 5.8(b). A probabilidade de \(X=i\) é \(1/36\) vezes o número total de maneiras pelas quais os dois dados podem somar \(i\). Assim, pela Tabela 5.8(b),

\[\begin{aligned} E(X) &=2\cdot\frac1{36}+3\cdot\frac2{36}+4\cdot\frac3{36} +5\cdot\frac4{36}+6\cdot\frac5{36}+7\cdot\frac6{36}\\ &\quad+8\cdot\frac5{36}+9\cdot\frac4{36}+10\cdot\frac3{36} +11\cdot\frac2{36}+12\cdot\frac1{36}\\ &=7. \end{aligned}\]

Essa resposta faz sentido, pois o valor central é \(7\) e, para todo inteiro \(j\), \(X\) tem a mesma probabilidade de assumir \(7+j\) e \(7-j\).

O nome valor “esperado” é um pouco enganoso: como a esperança \(E(X)\) é uma média ponderada, ela pode assumir um valor que a variável aleatória não assume de fato, como mostra o exemplo seguinte.

Exemplo5.36

Suponha que escolhamos ao acaso um inteiro entre os elementos de \(\{1,2,3,4,5,6\}\) e seja \(X\) o valor escolhido. Então \(\Pr(X=i)=1/6\) para cada \(1\le i\le6\), isto é, \(X\) é uniformemente distribuída. O valor esperado de \(X\) é

\[E(X)=\frac16(1+2+3+4+5+6)=\frac72.\]

Logo, a esperança de \(X\) é um valor que \(X\) não assume. Mais geralmente, o valor esperado de uma variável aleatória uniformemente distribuída em \(\{1,2,\ldots,N\}\) é \((N+1)/2\).

Exemplo5.37

Retomemos o experimento de lançar uma moeda do Exemplo 5.31, em que a probabilidade de obter cara em qualquer lançamento é \(p\). Seja \(X\) a variável aleatória igual a \(n\) quando a primeira cara aparece no \(n\)-ésimo lançamento. Então \(X\) possui densidade geométrica, e sua função densidade \(f_X(n)\) é dada pela fórmula (5.25). Calculamos \(E(X)\), o número esperado de lançamentos até a primeira cara:

\[\begin{aligned} E(X) &=\sum_{n=1}^{\infty}np(1-p)^{n-1} =-p\sum_{n=1}^{\infty}\frac{d}{dp}\bigl((1-p)^n\bigr)\\ &=-p\frac{d}{dp}\left(\sum_{n=1}^{\infty}(1-p)^n\right) =-p\frac{d}{dp}\left(\frac1p-1\right) =\frac{p}{p^2}=\frac1p. \end{aligned}\]

A resposta parece plausível: quanto menor o valor de \(p\), mais lançamentos esperamos precisar até obter a primeira cara. O cálculo de \(E(X)\) emprega um truque muito útil com derivadas, seguido da soma de uma série geométrica. Veja o Exercício 5.33 para outras aplicações desse método.
