A base de fatores limita quais decomposições serão consideradas fáceis. Uma base pequena simplifica a álgebra, mas torna relações completas raras; uma base grande faz o oposto.

  1. Seleção matemática. No crivo quadrático, só interessam primos para os quais N é resíduo quadrático, pois apenas eles dividem valores da forma \(x^2-N\) em progressões úteis.
  2. Seleção computacional. O limite B equilibra a probabilidade de suavidade com o número de colunas e relações necessárias.
  3. Sinal. Inclua −1 como elemento formal quando valores negativos são permitidos, para controlar a paridade do sinal.
Cuidado. “Base” aqui não significa base vetorial desde o início. É uma lista de fatores; seus vetores de paridade é que vivem num espaço sobre \(\mathbb F_2\).
