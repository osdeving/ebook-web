O teste de Fermat explora uma condição necessária para primos, mas alguns compostos imitam essa condição para muitas bases — e os números de Carmichael a imitam para todas as bases coprimas.

  1. Teste. Para uma base a coprima com N, verifique \(a^{N-1}\equiv1\pmod N\).
  2. Falha conclusiva. Se a congruência falhar, N é composto.
  3. Sucesso inconclusivo. Se passar, a estrutura do grupo pode ter alinhado o expoente mesmo com N composto. Miller–Rabin observa também as raízes quadradas de 1 na cadeia.
Cuidado. Testar mais bases de Fermat não elimina os números de Carmichael. É preciso fortalecer a condição, não apenas repetir a mesma condição.
