Dica 1 — Liste apenas as unidades

Para os módulos pequenos, risque os resíduos que compartilham algum fator primo com o módulo.

Dica 2 — Multiplicar por uma unidade permuta

Se \(r_1,\ldots,r_{\varphi(N)}\) são as classes invertíveis, mostre que \(ar_1,\ldots,ar_{\varphi(N)}\) são as mesmas classes em outra ordem.

Dica 3 — Cancele o produto

Compare os produtos das duas listas. O produto \(r_1\cdots r_{\varphi(N)}\) também é uma unidade módulo \(N\), portanto pode ser cancelado.

Ver solução completa

  1. As classes invertíveis em cada caso são

    \[ \begin{aligned} (\mathbb Z/6\mathbb Z)^*&=\{1,5\}, &\varphi(6)&=2,\\ (\mathbb Z/9\mathbb Z)^*&=\{1,2,4,5,7,8\}, &\varphi(9)&=6,\\ (\mathbb Z/15\mathbb Z)^*&=\{1,2,4,7,8,11,13,14\}, &\varphi(15)&=8. \end{aligned} \]

    Como \(17\) é primo, todos os resíduos \(1,2,\ldots,16\) são invertíveis, de modo que \(\varphi(17)=16\).

  2. Se \(p\) é primo, somente a classe \(0\) entre as \(p\) classes não possui inverso. Portanto

    \[\varphi(p)=p-1.\]

  3. Sejam \(r_1,\ldots,r_{\varphi(N)}\) representantes de todas as classes invertíveis módulo \(N\), e suponha \(\gcd(a,N)=1\). Cada \(ar_i\) é invertível. Além disso, se

    \[ar_i\equiv ar_j\pmod N,\]

    podemos cancelar \(a\) e concluir \(r_i\equiv r_j\pmod N\). Logo multiplicar por \(a\) apenas permuta a lista das unidades. Comparando os produtos antes e depois da permutação,

    \[ (ar_1)(ar_2)\cdots(ar_{\varphi(N)}) \equiv r_1r_2\cdots r_{\varphi(N)}\pmod N. \]

    Assim,

    \[a^{\varphi(N)}R\equiv R\pmod N,\qquad R=r_1r_2\cdots r_{\varphi(N)}.\]

    Como \(R\) é produto de unidades, também é uma unidade e pode ser cancelado. Portanto

    \[a^{\varphi(N)}\equiv1\pmod N,\]

    que é a fórmula de Euler.
