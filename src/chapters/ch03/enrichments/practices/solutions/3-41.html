Dica 1 — Multiplique as raízes cúbicas

Se \(a\equiv c^3\) e \(b\equiv d^3\), então \(ab\equiv(cd)^3\pmod p\).

Dica 2 — O menor exemplo está módulo \(7\)

Liste os cubos não nulos módulo \(7\) e experimente \(a=b=2\).

Dica 3 — Veja a aplicação cúbica no grupo cíclico

Se \(a=g^r\), ser cubo equivale a resolver \(3k\equiv r\pmod{p-1}\). Quando \(p\equiv2\pmod3\), o número \(3\) é invertível módulo \(p-1\).

Ver solução completa

  1. Se \(a\equiv c^3\pmod p\) e \(b\equiv d^3\pmod p\), com \(c,d\not\equiv0\pmod p\), então

    \[ ab\equiv c^3d^3=(cd)^3\pmod p. \]

    Além disso \(cd\not\equiv0\pmod p\). Logo \(ab\) é resíduo cúbico.

  2. Tome \(p=7\), que satisfaz \(7\equiv1\pmod3\). Os cubos módulo \(7\) são

    \[ \{c^3\bmod7:c=0,1,\ldots,6\}=\{0,1,6\}. \]

    Escolha \(a=b=2\). Então \(a=2\), \(b=2\) e \(ab\equiv4\pmod7\); nenhum dos três pertence a \(\{1,6\}\). Portanto nenhum deles é resíduo cúbico.

  3. Seja \(g\) uma raiz primitiva e escreva \(a\equiv g^r\), com \(0\le r<p-1\). Como \(p\equiv1\pmod3\), temos \(3\mid p-1\).

    Se \(a\) é cubo, existe \(k\) tal que

    \[ g^r\equiv(g^k)^3=g^{3k}\pmod p. \]

    Logo \(r\equiv3k\pmod{p-1}\). Reduzindo módulo \(3\), concluímos \(3\mid r\). Reciprocamente, se \(r=3k\), então \(a\equiv(g^k)^3\pmod p\). Assim,

    \[ a\text{ é resíduo cúbico} \quad\Longleftrightarrow\quad 3\mid\log_g(a). \]

  4. Agora suponha \(p\equiv2\pmod3\). Então \(\gcd(3,p-1)=1\), de modo que elevar ao cubo é uma permutação do grupo \(\mathbb F_p^*\). Explicitamente,

    \[ d=\frac{2p-1}{3} \]

    é inteiro e satisfaz \(3d=2(p-1)+1\). Para \(a\not\equiv0\pmod p\), tome \(c\equiv a^d\pmod p\). Pelo pequeno teorema de Fermat,

    \[ c^3\equiv a^{3d} =a^{2(p-1)+1} \equiv a\pmod p. \]

    Se \(a\equiv0\pmod p\), basta escolher \(c=0\). Portanto todo inteiro é um cubo módulo \(p\) quando \(p\equiv2\pmod3\).
