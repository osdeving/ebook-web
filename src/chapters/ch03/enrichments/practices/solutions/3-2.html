Dica 1 — Escreva tudo em uma raiz primitiva

Para \(p\gt2\), escolha uma raiz primitiva \(g\) e escreva \(c=g^k\) e \(x=g^r\). A equação de potências vira uma congruência linear para \(r\).

Dica 2 — Use o critério da congruência linear

A congruência \(er\equiv k\pmod{p-1}\) possui solução exatamente quando \(\gcd(e,p-1)\mid k\); quando é solúvel, conte suas classes de solução.

Dica 3 — Conte a imagem, não as tentativas

No item (b), conte quantos expoentes \(k\) módulo \(p-1\) são múltiplos de \(\gcd(e,p-1)\).

Ver solução completa

Ponha \(n=p-1\) e \(d=\gcd(e,n)\). O caso \(p=2\) é imediato, portanto suponhamos \(p\gt2\). Pelo teorema da raiz primitiva, existe \(g\) que gera \(\mathbb F_p^*\). Há expoentes únicos \(k,r\pmod n\) tais que

\[c\equiv g^k\pmod p,\qquad x\equiv g^r\pmod p.\]

Consequentemente,

\[x^e\equiv c\pmod p\quad\Longleftrightarrow\quad er\equiv k\pmod n.\]

  1. Uma congruência linear \(er\equiv k\pmod n\) é solúvel se, e somente se, \(d\mid k\). Quando isso ocorre, divida por \(d\):

    \[\frac edr\equiv\frac kd\pmod{n/d}.\]

    Como \(\gcd(e/d,n/d)=1\), existe uma única solução \(r_0\pmod{n/d}\). Suas classes módulo \(n\) são

    \[r_0,\ r_0+\frac nd,\ \ldots,\ r_0+(d-1)\frac nd.\]

    Elas são distintas e totalizam exatamente \(d=\gcd(e,p-1)\) soluções para \(x\).

  2. Os valores de \(c=g^k\) que admitem raiz são precisamente aqueles com \(d\mid k\). Entre as \(n=p-1\) classes de expoentes existem

    \[\frac nd=\frac{p-1}{\gcd(e,p-1)}\]

    múltiplos de \(d\). Portanto esse é o número de valores não nulos de \(c\pmod p\) para os quais a congruência possui solução. Equivalentemente, a aplicação \(x\mapsto x^e\) tem fibras de tamanho \(d\) e imagem de tamanho \((p-1)/d\).
