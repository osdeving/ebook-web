Dica 1 — Separe os primos ímpares pelo resto

Depois de retirar o primo \(2\), todo primo deixa resto \(1\) ou \(3\) na divisão por \(4\). Conte essas duas listas separadamente.

Dica 2 — Adapte o crivo

Ao encontrar um índice primo \(p\), incremente o contador apropriado conforme \(p\bmod4\). Não conte \(2\) em nenhum dos dois.

Dica 3 — Distinga tendência de igualdade

Os dados podem favorecer uma classe para todos os limites testados e, ainda assim, a razão tender a \(1\). Observe a distância da razão até \(1\).

Ver solução completa

  1. As contagens diretas são:

    \[ \begin{array}{c|l|l|c|c} X&p\equiv1\pmod4&p\equiv3\pmod4&\pi_1(X)&\pi_3(X)\\ \hline 10&5&3,7&1&2\\ 25&5,13,17&3,7,11,19,23&3&5\\ 100& 5,13,17,29,37,41,53,61,73,89,97& 3,7,11,19,23,31,43,47,59,67,71,79,83& 11&13 \end{array} \]

  2. O mesmo crivo do exercício anterior pode devolver os dois contadores:

    function piMod4(X) {
  const prime = Array(X + 1).fill(true);
  prime[0] = prime[1] = false;
  for (let p = 2; p * p <= X; p++) {
    if (prime[p]) {
      for (let m = p * p; m <= X; m += p) prime[m] = false;
    }
  }
  let p1 = 0, p3 = 0;
  for (let p = 3; p <= X; p += 2) {
    if (prime[p]) p % 4 === 1 ? p1++ : p3++;
  }
  return { p1, p3 };
}

    Os resultados verificados são

    \[ \begin{array}{c|r|r|c} X&\pi_1(X)&\pi_3(X)&\pi_3(X)/\pi_1(X)\\ \hline 100&11&13&1{,}181818\\ 1000&80&87&1{,}087500\\ 10000&609&619&1{,}016420\\ 100000&4783&4808&1{,}005227 \end{array} \]

  3. Nos quatro limites amostrados, \(\pi_3(X)>\pi_1(X)\), então os dados sugerem um viés a favor dos primos congruentes a \(3\pmod4\). Ao mesmo tempo, a razão cai de aproximadamente \(1{,}18\) para \(1{,}005\). A conjectura natural é

    \[\boxed{\displaystyle\lim_{X\to\infty}\frac{\pi_3(X)}{\pi_1(X)}=1.}\]

    Isso afirma igualdade assintótica, não que \(\pi_3(X)\) precise ser maior para todo \(X\). O fenômeno observado é conhecido como viés de Chebyshev: uma classe pode liderar com frequência, embora as duas tenham a mesma densidade assintótica.
