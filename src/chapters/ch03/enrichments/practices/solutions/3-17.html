Dica 1 — Liste os primos pequenos

Para o item (a), conte \(2,3,5,7,11,13,17,19,\ldots\) sem incluir números maiores que o limite.

Dica 2 — Use um crivo

No item (b), marque os múltiplos de cada primo \(p\le\sqrt X\). Os índices ainda não marcados são exatamente os primos até \(X\).

Dica 3 — A razão deve tender a \(1\)

Calcule \(\pi(X)\ln X/X\). O teorema dos números primos prevê que esses valores se aproximem de \(1\), sem exigir monotonicidade.

Ver solução completa

  1. Os primos até \(20\) são

    \[2,3,5,7,11,13,17,19,\]

    de modo que \(\pi(20)=8\). Acrescentando \(23,29\), obtemos \(\pi(30)=10\). A lista completa até \(100\) contém \(25\) primos, logo

    \[\boxed{\pi(20)=8,\qquad\pi(30)=10,\qquad\pi(100)=25.}\]

  2. Uma implementação direta do crivo de Eratóstenes é:

    function pi(X) {
  const prime = Array(X + 1).fill(true);
  prime[0] = prime[1] = false;
  for (let p = 2; p * p <= X; p++) {
    if (prime[p]) {
      for (let m = p * p; m <= X; m += p) prime[m] = false;
    }
  }
  return prime.reduce((total, value) => total + Number(value), 0);
}

    O programa dá:

    \[ \begin{array}{c|r|c} X&\pi(X)&\pi(X)/(X/\ln X)\\ \hline 100&25&1{,}151293\\ 1000&168&1{,}160503\\ 10000&1229&1{,}131951\\ 100000&9592&1{,}104320 \end{array} \]

    As razões ainda oscilam e, nesse trecho, descem lentamente em direção a \(1\). Isso é plenamente compatível com

    \[\lim_{X\to\infty}\frac{\pi(X)}{X/\ln X}=1,\]

    portanto os dados tornam o teorema dos números primos plausível, embora naturalmente não constituam uma demonstração.
