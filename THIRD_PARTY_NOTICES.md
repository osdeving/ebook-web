# Avisos de terceiros

O build usa software de terceiros mantido em suas licenças próprias. As
dependências diretas distribuídas no runtime desta versão são:

| Pacote | Versão resolvida | Licença | Projeto |
|---|---:|---|---|
| Astro | 7.2.0 | MIT | <https://astro.build/> |
| Integração React para Astro | 6.0.2 | MIT | <https://docs.astro.build/en/guides/integrations-guide/react/> |
| React | 19.2.8 | MIT | <https://react.dev/> |
| React DOM | 19.2.8 | MIT | <https://react.dev/> |
| KaTeX | 0.16.47 | MIT | <https://katex.org/> |

Versões, integridade e licenças declaradas das dependências transitivas ficam
registradas em `package-lock.json` e nos respectivos pacotes instalados. Este
arquivo não substitui os textos integrais das licenças.

Conteúdo editorial, tradução e imagens não pertencem a esta lista. Consulte
`CONTENT_LICENSE.md`, `src/chapters/<slug>/credits.md` e os créditos próximos
a cada ativo.
